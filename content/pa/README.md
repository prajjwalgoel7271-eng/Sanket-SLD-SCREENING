# Architecture-Ready Content Bank

This directory is pre-configured and architecture-ready for Punjabi (pa).
Core Python logic in detection/dyslexia.py will automatically load files from this folder when pa is selected.

CRITICAL NOTE ON MULTILINGUAL CONTENT:
Do NOT auto-translate phonological/nonword content using generic translation APIs (e.g. Google Translate).
Phonological tasks (rhymes, sound blending) and nonword lists MUST be independently constructed by native linguists/special educators according to Punjabi phonotactic and phonetic rules.
